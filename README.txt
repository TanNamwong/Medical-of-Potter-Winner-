สุขภาพลูก (PWA) — วิธีติดตั้งขึ้น GitHub Pages
1) แตก ZIP แล้วอัปโหลดไฟล์ทั้งหมดไปที่ root ของ repo (ระดับเดียวกับ index.html)
2) เปิด Settings > Pages ให้เผยแพร่จาก branch หลัก แล้วเปิดลิงก์ https ของเว็บ
3) Android: จะมีแถบ/ปุ่ม “ติดตั้ง”  |  iPhone: เปิดด้วย Safari แล้วทำตามแถบแนะนำ (แชร์ > เพิ่มไปยังหน้าจอโฮม)

ปล่อยเวอร์ชันใหม่:
- แก้ CACHE_NAME ใน service-worker.js ให้ต่างจากเดิม (เช่น kids-health-v1.0.1)
- แก้ APP_VERSION ใน index.html ให้ตรงกัน
- อัปโหลดทับ เครื่องผู้ใช้จะเห็นแถบ “มีเวอร์ชันใหม่” และจุดแดงที่เมนูเพิ่มเติม
